# Machine Learning Projects

## Human Activity Recognition Using Smartphone Sensors

Compare Logistic Regression, RBF SVM, and Random Forest for six activities using 561 precomputed sensor features from the UCI HAR dataset.

Recorded notebook results: **95.49% test accuracy** and **0.9547 macro F1** for Logistic Regression. These are exploratory baseline results; the models were compared using test-set performance.
